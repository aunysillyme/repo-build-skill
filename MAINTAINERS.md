# Maintainers

Owner: [Auny LLC through the public repository account](https://github.com/aunysillyme).
Path ownership: [.github/CODEOWNERS](.github/CODEOWNERS).

- Scope: skill method, checker, installer, adapters, generated files and release operations.
- Review: require reproducible evidence, source attribution and checks appropriate to the change.
- Publication: the owner authorizes registry publishing, visibility changes and venue submissions.
- Support: best effort through issue forms and pull requests.
- Security: use [private reporting](SECURITY.md).
- Conduct: follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Continuity: keep release authority with an accountable maintainer who can review the artifact.
- Succession: record accepted ownership changes here and in CODEOWNERS before granting release access.
